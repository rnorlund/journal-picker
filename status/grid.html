Review speed is no longer blocked. PubMed carries publisher-deposited received→accepted dates per article, so median time in review is computable from primary data. It was on this board as "no open dataset exists" — there is one, it just is not advertised as one. Coverage varies by publisher, so every figure ships with its sample size.

Still genuinely blocked: accept/reject rates. No open source has them, and unlike review times there is no proxy hiding in the data. Publisher self-reports plus hand-curation, labelled per subject area, is the only honest route.

Netlify production deploys are refused (drafts still work), almost certainly free-tier bandwidth — my own test runs pulled multi-MB catalogs over the CDN on every invocation. Tests are local-only now; one deploy at the end.
